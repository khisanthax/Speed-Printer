# Architecture

## Runtime boundary

`src/main.ts` renders the approved fixed desktop shell. Vite builds a static TypeScript client for GitHub Pages. `src/domain.ts` owns preset validation, inheritance, unit formatting, tuning ranges and demo data. The three settings panels share identical rows and scroll offsets. Printer photos are displayed from the exact approved reference asset through CSS positioning; no inferred hardware specifications are added.

The browser calls `helper/server.py` over authenticated loopback HTTP. Native dialogs mediate profile reads, model selection and installation. The Windows tray entry point uses pystray/Pillow and tkinter; cryptography verifies P-256 proofs and DPAPI protects local state. PyInstaller builds a windowed EXE. No Electron, cloud account or database is used. Orca is a separately installed dependency, never bundled. Slicing jobs are serialized on one worker to bound resource use; up to four jobs can be outstanding. Results remain session-local.

## Contracts

- `GET /health`: helper version, instance identifier and executable availability.
- `POST /auth/challenge`, `/auth/pair`, `/auth/resume`: exact Host/Origin checked, bounded one-use challenge/proof exchange. Initial pairing additionally requires the tray-issued five-minute code. Session tokens last at most eight hours; restarts retain public-key trust, not sessions.
- `POST /auth/revoke`: revoke this authenticated browser; tray Settings revokes all.
- `GET /library`: protected cached curated library; `POST /profiles` incrementally refreshes after one native approval, `{all:true}` deliberately loads full catalog.
- `GET/POST /workspace`: DPAPI-protected comparison snapshots, separate from source presets.
- `POST /profiles {chooseRoot?}`: permission-gated JSON discovery; returns named presets.
- `POST /model {bundles:[A,B,C]}`: native STL/3MF picker; snapshots the file locally and derives the shared rectangular bed intersection. Returns an opaque session ID and filename, never a browser-selected filesystem path. The client requires the `/health` sharedLayout capability (helper 0.3.0). Legacy callers without bundles retain the old path, but cannot be used by the new unified client.
- `POST /slice {bundle,model}`: validates and flattens the selected machine/process/filament, then returns a job ID.
- `GET /jobs/:id`: pending, running, complete/result or failed/error.
- `POST /analyze {bundle,target,model,keys}`: 1–8 one-at-a-time substitutions plus cumulative ranked substitutions.
- `POST /install {bundle,name}`: exact validated-settings requirement, native account directory choice and confirmation, exclusive create of three renamed presets.
- `POST /history {url,apiKey?}`: fixed read-only Moonraker `/server/history/list?limit=100&order=desc`.
- `POST /limits {url,apiKey?}`: fixed read-only `/printer/objects/query?toolhead&configfile`.

Every endpoint requires an exact allowed Origin and `Host: 127.0.0.1:8377`. Non-auth endpoints additionally require a matching session bearer token. Preflight requires Host/Origin but not the token. No wildcard CORS or cookie authentication is used. Browser token state and Moonraker keys are in memory. The browser's platform local-network policy may require local use of the web app.

## Slicing provenance

`helper/core.py` continues to invoke the installed Orca binary with argument arrays and the existing single helper worker. `helper/shared_model.py` owns immutable input snapshots and comparison layout provenance. The first slice request performs one **arrangement/export-only** Orca pass (`--arrange 1`, `--export-3mf`, no `--slice`), using the shared rectangular bed intersection solely for layout preparation. It verifies printable-instance count and one occupied plate. Each actual estimate then uses the untouched selected machine/process/material settings with `--arrange 0`, `--slice 0` and `--export-3mf`.

Orca recenters imported 3MF instances when embedded bed dimensions change, even with arrangement disabled. Each private input therefore updates only the embedded machine bed frame to the actual selected machine before loading its settings; meshes, copies, transforms and object/part overrides stay fixed. Actual exported results are read back and checked against the common layout. The signature uses world-space mesh geometry (including composed component/instance transforms), quantities, plate membership and object/part print conditions. UUIDs and unordered metadata serialization are ignored; physical positions are normalized at 1e-7 mm to avoid serialization-only float differences. The representation must tolerate STL transforms moving between component and instance levels without masking a real translation. Source-model SHA256 and common layout SHA256 are returned with each successful estimate.

Temporary directories isolate every slice, and up to eight selected model snapshots stay private in the helper session. Nonzero exit, absent G-code, missing normal-mode time, altered common conditions or multiple occupied plates are failures. Cache identity includes model, layout, settings and engine fingerprint; export always performs a fresh slice. No alternative time estimator or new execution queue is used.

The existing client dispatcher now serializes A/B/C intents before submission to the existing helper worker. A set retains at most one pending request per column, captured only when dispatched. C changes debounce 650 ms; model/profile revisions and exact snapshot keys gate completions. An identical completed source result is reusable for C, avoiding a duplicate engine slice. Changing the model clears pending old-model intents/cache and invalidates every summary. C-only changes preserve A/B results. Failed current slices clear their estimate and verification status. Unchanged background profile refresh no longer recreates active range/input nodes. Unrelated tuning does not discard a still-valid baseline result. Adjustments debounce 650 ms; last estimates remain marked stale. Source metrics come exclusively from G-code comments. Missing breakdowns remain unavailable. Installation validation is session-local and must match the flattened bundle hash exactly.

## Controlled experiments

For each selected key, replace only its value with the target value and measure a real slice. Rank seconds saved against the baseline, then apply the ranked settings cumulatively and re-slice after each. Conditional gains show the effect after prior changes; the interaction residual is combined improvement minus the sum of isolated improvements. This detects interactions along one chosen path without claiming a full factorial study. No numerical search bypasses flow or machine limits. Quality-affecting controls are explicit choices.

## Persistence and installation

Experiments persist in browser localStorage. Browser identity is an opaque non-exportable P-256 CryptoKey persisted by IndexedDB structured clone; its public key is registered in the helper DPAPI store. Page scripts cannot extract private bytes but can request signing on the trusted origin. Only ephemeral bearer tokens and Moonraker data stay in memory. Model IDs are session-local: after helper restart the app marks estimates stale and requests the model again. The helper persists approved curated profile metadata/settings and comparison snapshots with DPAPI. Incremental stat manifests skip unchanged JSON/OPC reads; stable reads and last-good snapshots tolerate active writes. Source hashes flag changed or missing presets without altering experiments. Renames appear as a missing source plus a newly discovered preset; no filename/mtime guessing remaps an experiment. Exports contain three flattened JSON presets. Installation creates `machine/<new-name> - machine.json`, `process/<new-name> - process.json` and `filament/<new-name> - filament.json` below the locally selected account folder. It updates names/settings IDs and custom-user markers. Existing paths fail; partial creates roll back. Open a new Orca window after installation to load disk presets; preserve existing unsaved projects. No original profile is modified.

## Testing and operational limits

Unit tests cover recursive inheritance errors, percentage/array preservation, parameter constraints, G-code provenance, interaction math, installation rollback, auth/Host/Origin checks and restricted Moonraker requests. Browser tests cover the three-column layout, synchronized scrolling, empty/pending summaries, saved experiments and missing history metadata. CI builds an unsigned helper artifact and deploys static hosting.

Physical printer safety, actual vs estimated calibration and Orca GUI account discovery require local hardware validation. Moonraker history does not establish original settings or feature timing. See the logbook for observed engine compatibility and end-to-end evidence.

System discovery reads JSON and Orca `.opc` binary cache format 2. The bounded cache reader checks the magic, version, size, CRC, dictionary indices and complete consumption. It decodes named enums, vectors, percentages and grouped values to Orca JSON representations; unknown formats fail closed with a warning. Vendor/account namespaces disambiguate shared base names, includes layer below the preset's own values, and later configured roots supersede earlier roots within a namespace. No binary cache is executed or deserialized through Python object constructors. Protocol references: [Orca preset cache format](https://github.com/OrcaSlicer/OrcaSlicer/blob/v2.5.0/src/libslic3r/PresetCacheFormat.cpp), [CLI](https://github.com/OrcaSlicer/OrcaSlicer/wiki/cli_mode), [Moonraker history](https://moonraker.readthedocs.io/en/latest/external_api/history/).

Personal comparison uses all printable instances arranged once onto one common plate, with scope and generated object count returned alongside the estimate. A narrowly bounded inactive raft sentinel repair affects only the temporary snapshot and is disclosed in result notes. The original source hash remains the cache/provenance identity. Common-process mode copies the complete inherited process from A onto B, retaining B’s machine and calibrated filament; imported processes can be restored. It does not claim to equalize every machine/material constraint or expose implicit engine defaults. Connection and credential fields are excluded from discovered/effective presets.

`POST /export-project {bundle,model}` opens a native save picker and queues a fresh slice into an exclusively created 3MF file. It does not overwrite source projects or dispatch a print. This preserves the exact comparison arrangement for Orca GUI use. Motion-limit analysis groups are explicit simulations: X/Y jerk is substituted together, or the extruding acceleration cap alone, with ordinary isolated/cumulative measurement. The client prevents applying any simulation-containing result.

The tray owns a per-user Windows mutex and activation event. Relaunch signals the existing Settings window. A hidden tkinter owner keeps Settings independent of helper lifetime; pystray provides status/menu controls. Opt-in HKCU Run startup uses the existing executable, default off. Restart waits for idle jobs, reconstructs sessions from protected trust and preserves imported profiles. Production has no legacy token pairing: only explicitly constructed test fixtures expose the old protocol.

## Automatic local trust discovery

The browser probes only the fixed numeric loopback endpoint `/discover`, restricted by exact Host/Origin checks and exposing no library or secrets. `/auth/challenge` reports whether that browser identity is already trusted or explicitly revoked. Existing trust resumes with a signed challenge. A new identity sends its public key and signature to `/auth/approve`; proof verification precedes a rate-limited native origin-naming dialog, and only approval persists the public key with Windows DPAPI. No silent grant or trust replacement is allowed. Revocation persists across helper restarts and blocks automatic approval until explicit fallback-code pairing. Short fallback codes retain the original rate limits, expiry and one-use semantics. The frontend serializes connection attempts and suppresses repeated declined prompts for a helper instance. Private routes keep session authentication in addition to Origin/Host validation. Browser network permission remains independent of helper trust.
